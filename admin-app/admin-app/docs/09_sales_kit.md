## Quick Reference (Admin Context)

The Admin Portal is **The Command Center** of the Travel Lounge ecosystem:

- **Dynamic Pricing Engine** — Seasonal grid, occupancy tiers (Adult/Teen/Child/Infant), meal plan supplements.
- **Inventory Guardrails** — Stop-Sell toggles and stock counters prevent overbooking instantly.
- **Production-Grade SMTP** — Hardened email infrastructure for transactional booking/inquiry notifications.
- **CMS Engine** — Non-technical staff can update Hero banners, amenities, and service descriptions instantly.
- **Room & Configuration Manager** — Dedicated UI for room-level occupancy limits independent of pricing.

For the full ecosystem Sales Kit, see the canonical document linked above.
