# 03 Feature Catalog

The Royal Travel Agency Ecosystem is a comprehensive travel management suite designed for high-fidelity guest experiences and operational excellence.

## Guest-Facing Features (Web App)

### 1. Universal Multi-Field Search
- **Functionality:** crawls across Name, Location, Region, Service Type, and Description.
- **Benefit:** Instant discovery regardless of user intent (e.g., "Hilton", "Grand Baie", "Spa").

### 2. Dynamic Pricing Engine
- **Functionality:** Real-time calculation based on check-in/out, guest age tiers (Adult/Teen/Child/Infant), and seasonal overrides.
- **Benefit:** Accurate, trust-building pricing without manual calculations.

### 3. Integrated Booking Journey
- **Functionality:** A full-page, mobile-optimized scrolling wizard with duration presets and real-time tax validation.
- **Benefit:** High conversion via reduced cognitive load.

### 4. Advanced Filtering System
- **Functionality:** Multi-criteria filtering by Budget, Region, Star Rating, Amenities, and Meal Plans.
- **Benefit:** Precise refinement for targeted travel planning.

### 5. Smart Date Intelligence
- **Functionality:** Context-aware pickers (Range for Hotels, Single-Date for Activities) with integrated Stop-Sell blocking.
- **Benefit:** Error-free date selection aligned with service availability.

---

## Administrative Features (Admin Portal)

### 1. Seasonal Price Manager
- **Functionality:** High-density grid for monthly/daily price propagation across all occupancy tiers.
- **Benefit:** Dynamic revenue management with minimal manual effort.

### 2. Dynamic CMS Engine
- **Functionality:** Slug-based content management for 20+ page types, enabling real-time UI updates without code.
- **Benefit:** Marketing agility for non-technical staff.

### 3. Room & Inventory Control
- **Functionality:** Granular management of room types, occupancy limits, and individual unit availability.
- **Benefit:** 100% visibility into inventory stock and capacity.

### 4. Automated Notification Service
- **Functionality:** Branded, service-aware email triggers for Bookings, Inquiries, and Staff Alerts.
- **Benefit:** Professional, consistent communication across the customer lifecycle.

### 5. Role-Based Access Control (RBAC)
- **Functionality:** Secure access tiers for Admins, Managers, and Staff with audit-grade security.
- **Benefit:** Secure data isolation and operational governance.

---

## Mobile Concierge (Mobile App)
- **Concierge View:** Real-time access to guest bookings and itineraries.
- **On-the-Go Management:** Rapid check-in verification and service updates for field staff.
